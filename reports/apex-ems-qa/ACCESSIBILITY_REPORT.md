# Accessibility Report

## Source-level positives

- Forms use visible labels and standard controls.
- Buttons and icon actions include text or title attributes in the reviewed templates.
- Reduced-motion CSS is present.
- Semantic headings, tables and status badges are used in primary screens.

## Open verification

- Automated axe/pa11y run was not possible without a browser.
- Keyboard-only focus order, visible focus contrast, screen-reader announcements, table header associations, and modal confirmation behavior require browser verification.
- Color contrast needs actual rendered-theme measurement for both light and dark modes.

Status: **partially reviewed; not accessibility-certified**.
