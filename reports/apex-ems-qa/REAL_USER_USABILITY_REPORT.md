# Real User Usability Report

No real users were available and no browser connector was available. Therefore this is a **simulated usability report**, not user research.

## Simulated journeys

1. Admin login → dashboard → create employee → create attendance → create payroll → review payslip.
2. Employee login → view own employee record → submit leave → view own attendance/payroll → attempt another employee detail.
3. HR Manager login → review pending leave → approve/reject with a required note.
4. Any user → switch theme → revisit page; default follows operating-system preference until explicitly overridden.

## Observed source/test evidence

- Clear role-specific navigation and create controls are present.
- Login no longer displays usernames/passwords.
- Leave approval is a visible workflow rather than a free status edit.
- Unauthorized cross-record reads return 403 for protected self-service areas.

## Not validated

Task completion time, comprehension with real users, mobile touch behavior, visual hierarchy on actual devices, and assistive technology behavior require browser testing.
